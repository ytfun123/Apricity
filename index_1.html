Quick Reference
Common patterns and how to get your API key.
Getting an API Key
  1. Go to console.cloud.google.com
  2. Create a new project (or select existing)
  3. Go to APIs & Services → Library
  4. Search for YouTube Data API v3 and enable it
  5. Go to Credentials → Create Credentials → API Key
  6. Copy the key and paste it into your code
API Quota
Free tier: 10,000 units/day. Each search costs 100 units; reads cost 1–3 units.
